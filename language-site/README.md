# 语言与站点切换 Demo

基于兆材云库找物料页面的交互演示。

- 顶部入口单行显示站点、当前语言和币种，如 China · 中国站 · 简体中文 · CNY。
- 设置面板先选择站点，再选择语言。
- 中国站、日本站支持切换币种；国际站展示币种，固定为 USD。
- 固定的语言和币种统一显示黄色选中块与勾选图标，无下拉箭头且不可操作。
- 中国站币种顺序：CNY、USD、EUR、GBP、HKD、SGD、JPY。
- 日本站币种顺序：SGD、CNY、USD、EUR、GBP、HKD、JPY。
- 叉号取消，勾号应用设置。
- 确认按钮直接应用当前选项，不依赖浏览器的表单提交。
- 支持偏好记忆及手机布局。

`index.html` 已内嵌样式、脚本与示例图片，无须构建。页面中的站点、商品译文和汇率仅用于交互演示。
