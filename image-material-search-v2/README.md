# 单品图找物料 / 空间图找物料 Demo V2

这是一个与旧页面隔离的纯静态交互 Demo，不需要安装依赖。

## 打开方式

直接打开 `index.html`。主要验收浏览器为最新版 Chrome 和 Edge，建议使用 1440px 或更宽的桌面窗口。

## 演示状态

- `index.html`：找物料入口页，左侧提供“空间图找物料”图片入口，顶部提供“单品图找物料”入口
- `index.html?demo=loading`：正在识图
- `index.html?demo=recognized`：识别完成并默认选中第一个识别物体
- `index.html?demo=empty`：未识别到物体，默认展示原图搜索结果
- `index.html?demo=object`：已选择沙发
- `index.html?demo=selected`：已选择多个物料
- `index.html?demo=drawer`：打开已选物料 Drawer
- `index.html?demo=material`：找面料/材质并打开分类弹层
- `download-center.html`：个人中心的物料清单下载中心

## 交互范围

- 找物料页双入口及对应上传意图
- 本地图片上传、更换和清除
- 原图搜索与 Mock 识别延迟
- 识别成功后默认选择第一个对象；识别为空时回退原图
- 首次识别后的对象选择轻量指引
- 识别对象切换和原图区域高亮
- 原图直接拖拽框选局部搜索
- AI 家具 / AI 材质提取结果搜索
- AI 或框选结果选中物料后，动态加入顶部对象栏；取消最后一项后同步移除
- 相似物料与找面料/材质切换
- 分类、品牌、色系、价格和排序
- 物料选择、取消和清单 Drawer；结果卡不提供收藏或批量收藏入口
- 物料清单异步生成、取消、重新生成、上一版下载和生成成功后直接下载
- 物料清单底部可切换待生成、生成中、生成成功、清单已修改和生成失败等 Demo 状态
- 下载中心任务列表、状态筛选，以及下载、取消、重试和删除操作

顶部对象栏顺序为“原图 → 自动识别物体 → AI 结果 → 框选区域”。动态对象统一采用“AI 家具 01 / AI 材质 01 / 框选区域 01”的命名规则。真实 AI、真实搜索和加入项目不在本 Demo 范围内。
